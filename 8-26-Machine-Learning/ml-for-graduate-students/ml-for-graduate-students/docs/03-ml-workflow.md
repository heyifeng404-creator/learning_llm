# 03｜机器学习实验工作流

## 1. 从问题而不是模型开始

先写一页“任务契约”：

- 决策是什么？模型输出会被谁、在何时使用？
- 预测对象、观察单位和时间窗口是什么？
- 标签如何定义，何时可获得，噪声来自哪里？
- 错误的成本是否对称？假阳性和假阴性哪个更严重？
- 离线指标与真实效用之间有什么关系？
- 延迟、内存、隐私、公平和解释性约束是什么？

例如“预测流失”不够精确；更好的定义是：“使用截至每周一可获得的信息，预测活跃付费用户未来 30 天是否停止付费，为保留活动提供排序名单。”

## 2. 数据审计

检查以下问题：

- 每行代表什么？是否存在重复实体？
- 字段类型、单位、缺失含义和取值范围是什么？
- 标签分布是否不平衡？是否有错误标签？
- 数据是怎样被采集、过滤和标注的？
- 训练与应用人群是否一致？
- 同一用户/设备/病人是否跨训练和测试集？
- 特征在预测时是否真实可用？

缺失值不是单纯技术问题。“没测量”本身可能携带流程信息；填补时要只用训练集统计量，并考虑加入缺失指示变量。

## 3. 正确拆分数据

### 随机拆分

适合同分布、样本近似独立的场景。常见为训练/验证/测试三部分。测试集只用于最终一次无偏估计，不参与超参数选择。

### 分层拆分

分类中保持各集合类别比例接近，尤其适用于小样本和不平衡数据。

### 分组拆分

同一实体的记录必须放在同一侧。例如同一患者的多张影像不可跨集合，否则模型可能识别患者而非疾病。

### 时间拆分

训练只使用过去，验证与测试使用未来。任何使用未来统计量的特征都造成时间泄漏。

```text
时间 ──────────────────────────────>
训练窗口        验证窗口    测试窗口
[过去..........][之后......][未来......]
```

## 4. 数据泄漏

最常见、也最隐蔽的实验错误：

- 在全数据上标准化、选择特征或做 PCA 后再交叉验证。
- 输入中包含标签产生后的字段。
- 相同或近重复样本跨集合。
- 用测试集反复调参。
- 目标编码时用了当前样本或验证折的标签。

解决原则：所有会“学习数据统计量”的变换都必须在每个训练折内拟合。scikit-learn 的 `Pipeline` 是重要工具。

## 5. 建立基线

基线让改进有参照：

1. 业务规则或现有系统。
2. 常数预测：多数类、均值、中位数。
3. 简单模型：逻辑回归、小树、TF-IDF + 线性模型。
4. 强而成熟的模型：表格数据常用梯度提升树。

如果复杂模型只提高极少，要问成本是否值得、差异是否统计显著、是否来自泄漏。

## 6. 特征与预处理

- 数值特征：缺失填补、标准化、对数变换、截尾。
- 类别特征：one-hot、频率编码、谨慎的目标编码、embedding。
- 文本：词袋/TF-IDF、子词、预训练表示。
- 图像：缩放、归一化、合理增强。
- 时间：周期编码、滞后特征、滚动统计，严格防未来信息。

树模型通常不需要标准化；基于距离、内积和梯度的模型通常受尺度影响明显。

## 7. 训练与调参

调参流程：

```text
训练集
  └─ K 折交叉验证
      ├─ 每折内部拟合预处理
      ├─ 训练候选超参数
      └─ 计算验证指标
选择超参数 → 在完整训练集重训 → 测试集一次评估
```

随机搜索通常比网格搜索更高效；高成本任务可使用贝叶斯优化或多保真方法。搜索空间应按对数尺度设置学习率、正则强度等跨数量级参数。

## 8. 评估与误差分析

不要只报告总指标。至少按关键人群、时间、数据来源、难度和置信度分组。建立错误表，逐个检查高置信错误、低置信正确、假阳性和假阴性。

一个有效循环是：

```text
模型 → 错误切片 → 假设 → 收集证据/修改数据或模型 → 对照实验
```

误差分析往往比盲目换模型带来更大收益。

## 9. 复现清单

- 固定随机种子，但报告多种子均值和方差。
- 保存代码提交版本、依赖、配置和数据版本。
- 记录训练时长、硬件、预处理和停止条件。
- 保存最佳依据，不能只保存“最幸运的一次”。
- 将原始结果与绘图脚本一起保留。

## 10. 一个可靠实验的最小结构

```python
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

model = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("scale", StandardScaler()),
    ("clf", LogisticRegression(max_iter=2000)),
])
model.fit(X_train, y_train)  # 统计量只从训练数据获得
score = model.predict_proba(X_test)[:, 1]
```
