# 05｜无监督学习与表示

## 1. 为什么无监督学习更难评估

没有标签时，“正确结构”并不唯一。聚类结果取决于特征、距离、尺度和算法假设。无监督结果必须回到用途验证：是否帮助下游预测、检索、压缩、可视化或发现有意义群体？

## 2. K-Means

目标是最小化样本到所属中心的平方距离：

\[
\min_{\{\mu_k\},\{c_i\}}\sum_i\lVert x_i-\mu_{c_i}\rVert_2^2
\]

Lloyd 算法交替执行：分配到最近中心，再更新中心为簇均值。每步不增加目标，但只能保证局部最优，因此需多次初始化，通常使用 k-means++。

隐含假设：簇近似球形、尺度接近、欧氏距离有意义。特征应标准化。对非凸簇、离群点和不等密度结构表现差。

## 3. 高斯混合模型（GMM）

把数据看作多个高斯分布的混合：

\[
p(x)=\sum_{k=1}^{K}\pi_k\mathcal N(x\mid\mu_k,\Sigma_k)
\]

GMM 给出软分配概率，允许椭球形簇。通常用 EM 算法：

- E 步：计算每个样本属于各分量的后验责任度。
- M 步：用责任度加权更新混合权重、均值和协方差。

EM 也只保证局部收敛。可用 BIC/AIC 辅助选分量数，但仍需结合任务意义。

## 4. 层次聚类与 DBSCAN

层次聚类逐步合并或拆分簇，产生树状图。linkage 规则决定簇间距离：single 容易链化，complete 更紧凑，Ward 倾向最小化簇内方差。

DBSCAN 用密度连接区域形成簇：

- 能发现任意形状簇并标记噪声。
- 不必预先指定簇数。
- 对 `eps`、`min_samples` 和不同密度敏感。
- 高维空间距离退化时效果变差。

## 5. PCA

中心化后寻找保留最大方差的正交方向。等价地，PCA 寻找给定维数下平方重构误差最小的线性子空间。

步骤：

1. 只用训练集计算均值并中心化。
2. 对训练矩阵做 SVD。
3. 选择前 \(k\) 个右奇异向量。
4. 将训练和测试数据投影到同一组方向。

PCA 对尺度和离群点敏感；主成分最大化方差，不保证最有预测力，也不天然可解释。

## 6. 非线性可视化

- t-SNE：强调局部邻域，适合二维展示；簇间距离和簇大小不能直接解释。
- UMAP：兼顾局部结构和一定全局结构，速度较快；也受超参数和随机性影响。

不要根据一张漂亮的二维图断言原空间存在清晰类别。应报告预处理、参数、随机种子，并用下游任务或稳定性验证。

## 7. 自编码器

编码器把 \(x\) 压缩为 \(z\)，解码器从 \(z\) 重构 \(x\)：

\[
z=f_\phi(x),\qquad \hat x=g_\theta(z)
\]

若网络容量不受限制，它可能只学习复制输入。瓶颈、稀疏约束、去噪目标和变分约束会迫使表示捕获结构。线性自编码器在特定条件下与 PCA 密切相关。

## 8. 异常检测

异常可能是全局异常、条件异常或群体异常。常见方法：

- z-score / robust statistics：简单可解释。
- Isolation Forest：异常点更容易被随机切分孤立。
- One-Class SVM：学习包围正常样本的边界。
- 自编码器重构误差：高维数据常用，但异常也可能被很好重构。
- 密度模型：低概率不必然等于语义异常。

评估异常检测最好有少量标注或可模拟异常，并关注极低假阳性率下的召回。

## 9. 聚类评价

- 轮廓系数：簇内紧密与簇间分离的结合。
- Davies–Bouldin：簇内散度与簇间距离比，越小越好。
- 若有参考标签：ARI、NMI，但标签类别未必就是自然簇。
- 稳定性：换样本、初始化或小扰动后结果是否一致。

内部指标会偏好符合自身几何假设的结构，不能独立证明聚类有用。
