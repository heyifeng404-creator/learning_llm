# 02｜学习理论：为什么模型能够泛化

## 1. 经验风险与真实风险

真实目标是数据分布上的风险：

\[
R(f)=\mathbb E_{(X,Y)\sim P}[L(f(X),Y)]
\]

但分布 \(P\) 未知，只能最小化训练样本上的经验风险：

\[
\hat R_n(f)=\frac1n\sum_{i=1}^{n}L(f(x_i),y_i)
\]

泛化差距为 \(R(f)-\hat R_n(f)\)。学习理论关心：有限样本下，这个差距在什么条件下足够小？

## 2. 过拟合与欠拟合

- 欠拟合：训练误差和验证误差都高。模型、特征或优化能力不足。
- 过拟合：训练误差低而验证误差高。模型把偶然噪声当成规律。
- 优化不足：训练误差仍高，但原因是没训练好；不要误判为模型能力不足。

诊断时同时画训练/验证学习曲线。增加数据通常缓解方差问题，但不能自动修复标签错误、分布偏移和错误目标。

## 3. 偏差—方差分解

平方损失下，某点的期望预测误差可分为：

\[
\text{Error}=\text{Bias}^2+\text{Variance}+\text{Noise}
\]

- 偏差：模型平均预测与真实函数的差距，常来自过强假设。
- 方差：换一批训练数据，模型变化有多大。
- 不可约噪声：数据本身的随机性。

简单模型往往高偏差低方差，复杂模型往往低偏差高方差。这是理解正则化、集成和数据增强的统一框架，但现代深度学习中会出现双下降等更复杂现象，不能把它当绝对定律。

## 4. 模型复杂度

参数数量只是复杂度的粗略代理。更精确的刻画包括 VC 维、Rademacher complexity、范数、边界大小、压缩性与算法稳定性。重要直觉是：假设空间越灵活，需要越多数据或越强先验来约束。

典型泛化界具有形式：

\[
R(f)\lesssim\hat R_n(f)+O\left(\sqrt{\frac{\text{complexity}+\log(1/\delta)}{n}}\right)
\]

它说明样本数增大通常缩小不确定性，复杂度增大则提高过拟合风险。理论界常较松，主要用于比较趋势和建立概念，而不是精确预测测试误差。

## 5. 正则化的统一理解

显式正则化：

\[
\min_\theta \hat R(\theta)+\lambda\Omega(\theta)
\]

- L2：偏好小权重，等价于高斯先验下的 MAP。
- L1：偏好稀疏解，等价于 Laplace 先验下的 MAP。
- Elastic Net：L1 与 L2 的结合。

隐式正则化来自优化算法、初始化、网络结构、数据增强、早停和批量大小。即使训练损失为零，不同学习过程也可能偏向完全不同的解。

## 6. 归纳偏置

没有假设就无法从有限数据推广到未见数据。归纳偏置不是缺点，而是学习成立的前提：

- 线性模型假设效应可加且近似线性。
- CNN 假设局部模式重要并在空间中共享。
- RNN 假设序列状态可递归概括过去。
- Transformer 用注意力允许任意位置直接交互，并借助位置编码表达顺序。
- GNN 假设节点更新对邻居排列不敏感。

模型选择本质上是选择哪类先验更符合问题结构。

## 7. 数据量、维度与维度灾难

维度增加时，空间体积指数增长，有限样本变得稀疏，距离会失去区分度。KNN、密度估计等方法尤其敏感。应利用特征选择、降维、稀疏性、平滑性或结构先验。

“更多数据”有效的前提是数据与目标分布相关、标签质量可控，并覆盖真正关心的情形。

## 8. 分布外泛化

标准泛化讨论同分布测试。分布外泛化则要求模型面对新环境、群体或干预仍有效。常见策略包括：

- 收集覆盖目标环境的数据。
- 使用领域自适应或重要性加权。
- 学习稳定、因果或不变表示。
- 做压力测试、分群评估和最坏组风险评估。

没有关于变化机制的假设，不可能保证任意分布变化下都泛化。

## 9. No Free Lunch 的正确理解

不存在对所有可能任务都最优的学习算法。因此“哪个模型最好”缺少任务、数据规模、指标和约束时没有答案。好的研究不是寻找永远更强的方法，而是说明在什么条件下、为何、以何种代价更好。

## 10. 应能回答的问题

- 为什么训练误差不能代表测试误差？
- 正则化为何能以一点偏差换取更小方差？
- 数据增强为什么是一种结构先验？
- 参数更多是否必然更过拟合？为什么现代模型更复杂？
- 结论只在随机划分上成立，能否推广到未来数据或新域？
