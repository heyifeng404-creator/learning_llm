# 00｜机器学习知识地图

## 1. 先建立坐标系

机器学习不是算法清单，而是从数据中学习规律的一套方法论。一个问题通常由六个部分组成：

\[
\text{Problem}=\{\mathcal X,\mathcal Y,D,\mathcal F,L,A\}
\]

- 输入空间 \(\mathcal X\)：图片、文本、表格、图、时间序列等。
- 输出空间 \(\mathcal Y\)：实数、类别、序列、结构或动作。
- 数据 \(D=\{(x_i,y_i)\}_{i=1}^n\)：对真实数据分布的有限观测。
- 假设空间 \(\mathcal F\)：允许模型选择的函数集合。
- 损失函数 \(L\)：怎样量化预测错误。
- 学习算法 \(A\)：怎样从数据和目标中找到模型。

训练的典型形式是经验风险最小化：

\[
\hat\theta=\arg\min_\theta\frac1n\sum_{i=1}^{n}L(f_\theta(x_i),y_i)+\lambda\Omega(\theta)
\]

第一项要求拟合训练数据，第二项通过正则化限制模型复杂度。真正关心的是未知分布上的期望风险，而不是训练集分数。

## 2. 按“反馈信号”分类

| 范式 | 数据形式 | 目标 | 典型任务 |
|---|---|---|---|
| 监督学习 | \((x,y)\) | 从输入预测标签 | 分类、回归、排序 |
| 无监督学习 | \(x\) | 发现结构或表示 | 聚类、降维、密度估计 |
| 半监督学习 | 少量标签 + 大量无标签 | 利用无标签数据提升预测 | 医学影像、文本分类 |
| 自监督学习 | 从数据本身构造标签 | 学到可迁移表示 | 掩码预测、对比学习 |
| 强化学习 | 状态、动作、奖励 | 学习长期回报最大的策略 | 控制、博弈、决策 |
| 在线学习 | 连续到达的数据 | 边预测边更新 | 推荐、广告、流数据 |

## 3. 按任务输出分类

- 回归：输出连续值，如房价和温度。
- 二分类/多分类/多标签：类别互斥与否要区分。
- 排序：关心相对次序，而不只是独立分数。
- 结构化预测：输出序列、树、图或分割掩码。
- 生成：学习数据分布并产生新样本。
- 表示学习：把原始对象映射到有用的向量空间。
- 因果推断：回答“如果干预会怎样”，不能仅靠相关预测替代。

## 5. 三组核心矛盾

### 拟合与泛化

模型要捕获规律，又不能记住噪声。模型复杂度、数据量、正则化和早停都围绕这个矛盾展开。

### 表达能力与可学习性

函数族越强，理论上能表达的模式越多，但优化更难、所需数据更多、解释更复杂。深度网络成功并不只因为“容量大”，还因为结构、优化、数据和算力共同形成了合适的归纳偏置。

### 预测性能与其他目标

真实系统还关心延迟、成本、可解释性、公平性、隐私、鲁棒性、能耗和可维护性。单一离线指标不能代表系统价值。

## 6. 高频概念之间的关系

| 概念 | 回答的问题 | 容易混淆之处 |
|---|---|---|
| 参数 | 从数据中学到什么 | 线性模型权重、网络权重 |
| 超参数 | 学习前人为设置什么 | 学习率、树深、正则强度 |
| 损失 | 单个/一批样本错多少 | 训练时优化的量 |
| 指标 | 业务/研究上好不好 | 未必可微，未必等于损失 |
| 优化 | 如何找到低损失参数 | 优化好不等于泛化好 |
| 泛化 | 未见数据上是否有效 | 训练误差不能回答 |
| 校准 | 预测概率可信度如何 | 准确率高也可能不校准 |
| 不确定性 | 模型知道自己不知道吗 | 数据噪声与模型无知要区分 |

## 7. 数据分布视角

教科书常假设训练和测试样本独立同分布：

\[
(x_i,y_i)\overset{i.i.d.}{\sim}P(X,Y)
\]

现实中经常不成立：

- 协变量漂移：\(P(X)\) 改变，但 \(P(Y\mid X)\) 近似不变。
- 标签漂移：\(P(Y)\) 改变。
- 概念漂移：\(P(Y\mid X)\) 改变，这是更困难的情形。
- 选择偏差：进入数据集的样本不是总体的随机样本。
- 泄漏：训练时看到了预测时不可能获得的信息。

## 8. 研究生应具备的四层理解

1. **使用层**：能正确调用工具、拆分数据和解释指标。
2. **机制层**：能推导目标、理解优化过程和失败条件。
3. **比较层**：能识别方法间的假设、归纳偏置和计算代价。
4. **研究层**：能提出可证伪问题，设计对照与消融，并形成可靠结论。
