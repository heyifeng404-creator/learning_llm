# 12｜机器学习速查表

## 任务—损失—指标

| 任务 | 常用训练损失 | 常用评估指标 |
|---|---|---|
| 回归 | MSE、Huber、分位数损失 | MAE、RMSE、\(R^2\) |
| 二分类 | Binary cross-entropy | ROC-AUC、PR-AUC、F1、成本 |
| 多分类 | Cross-entropy | Macro/Micro F1、Top-k |
| 排序 | Pairwise/Listwise loss | NDCG、MAP、MRR |
| 分割 | CE、Dice、Focal | IoU、Dice |
| 生成 | NLL、对抗、去噪目标 | 困惑度、任务指标、人评 |

损失用于训练，指标用于评价；两者相关但不必相同。

## 预处理规则

| 模型 | 标准化 | 类别编码 | 缺失处理 |
|---|---|---|---|
| 线性/逻辑回归 | 推荐 | one-hot | 需要 |
| KNN/SVM | 必须重视 | one-hot | 需要 |
| 树/随机森林/GBDT | 通常不需要 | 视实现而定 | 视实现而定 |
| 神经网络 | 推荐 | one-hot/embedding | 需要或显式建模 |

所有预处理都只在训练数据拟合。

## 看到现象后的第一反应

| 现象 | 优先排查 |
|---|---|
| 训练和验证都差 | 特征、容量、优化、标签 |
| 训练好验证差 | 过拟合、泄漏、分布偏移 |
| 验证异常好 | 泄漏、重复样本、测试污染 |
| AUC 好但业务差 | 阈值、校准、指标错位 |
| 换种子波动大 | 样本小、训练不稳、切分敏感 |
| 部署后下降 | 训练服务偏差、漂移、反馈回路 |

## 常见超参数

- 线性模型：正则强度、L1/L2 比例。
- KNN：邻居数、距离、权重。
- SVM：\(C\)、kernel、\(\gamma\)。
- 树：深度、叶节点样本数、特征子采样。
- GBDT：树数、学习率、深度、行列采样。
- 神经网络：学习率、批大小、权重衰减、层宽深、dropout。

先调最影响容量和优化的参数，不要无目的搜索几十个参数。

## 必会公式

线性回归：

\[
\hat y=Xw+b,\qquad L=\frac1n\lVert\hat y-y\rVert^2
\]

Sigmoid 与二元交叉熵：

\[
p=\sigma(z),\qquad L=-[y\log p+(1-y)\log(1-p)]
\]

Softmax：

\[
p_k=\frac{e^{z_k}}{\sum_je^{z_j}}
\]

梯度下降：

\[
\theta\leftarrow\theta-\eta\nabla_\theta L
\]

Bayes：

\[
p(\theta\mid D)\propto p(D\mid\theta)p(\theta)
\]

Attention：

\[
\mathrm{softmax}(QK^T/\sqrt d)V
\]
