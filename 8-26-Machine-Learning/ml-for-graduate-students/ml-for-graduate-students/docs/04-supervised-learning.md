# 04｜监督学习算法

## 1. 线性回归

模型：

\[
\hat y=w^Tx+b
\]

最小化均方误差等价于假设噪声是独立同方差高斯分布时做最大似然估计。它的优势是简单、快速、可解释、适合当基线；局限是难以自动表达复杂非线性和特征交互。

### 正则化版本

- Ridge：\(\lVert y-Xw\rVert^2+\lambda\lVert w\rVert_2^2\)，相关特征较多时稳定。
- Lasso：\(\lVert y-Xw\rVert^2+\lambda\lVert w\rVert_1\)，可产生稀疏系数。
- Elastic Net：结合二者，适合成组相关特征。

系数解释依赖特征尺度、共线性和模型设定；“系数大”不自动意味着因果效应大。

## 2. 逻辑回归

二分类模型：

\[
P(y=1\mid x)=\sigma(w^Tx+b),\qquad \sigma(z)=\frac1{1+e^{-z}}
\]

它对对数几率建模：

\[
\log\frac{p}{1-p}=w^Tx+b
\]

使用二元交叉熵，即 Bernoulli 负对数似然。输出 0.5 阈值不是自然法则，应根据错误成本、资源和目标指标选择阈值。

多分类使用 softmax：

\[
P(y=k\mid x)=\frac{e^{z_k}}{\sum_je^{z_j}}
\]

## 3. K 近邻

对新样本找到距离最近的 \(K\) 个训练样本，分类用投票，回归用平均。

- 优点：无需显式训练，局部、直观。
- 缺点：预测慢、内存大、怕无关特征和维度灾难。
- 关键：特征标准化、距离度量、K 值。

K 小则低偏差高方差；K 大则边界更平滑但可能欠拟合。

## 4. 朴素贝叶斯

利用 Bayes 公式并假设给定类别后特征条件独立：

\[
P(y\mid x)\propto P(y)\prod_jP(x_j\mid y)
\]

独立假设通常不真实，但在文本词袋等高维稀疏任务中仍非常有效。训练快、数据需求低，是值得保留的基线。

## 5. 支持向量机与核方法

线性 SVM 寻找最大间隔分类超平面。软间隔目标可写为：

\[
\min_{w,b}\frac12\lVert w\rVert^2+C\sum_i\max(0,1-y_i(w^Tx_i+b))
\]

间隔越大，分类边界对扰动通常越稳健。核技巧用 \(K(x,x')=\langle\phi(x),\phi(x')\rangle\) 隐式进入高维特征空间。

- 适合中小规模、高维数据。
- RBF 核要重点调 \(C\) 和 \(\gamma\)。
- 大样本核矩阵成本高，概率输出也需额外校准。

## 6. 决策树

树递归选择特征和切分点，使子节点更纯。分类常用 Gini 或熵，回归常用平方误差。

- 优点：可表达非线性和交互，不要求标准化，能处理混合规律。
- 缺点：单树高方差、容易过拟合、切分不连续。
- 关键超参数：最大深度、叶节点最小样本数、剪枝强度。

特征重要性不等于因果重要性；基于纯度的特征重要性偏爱取值多的特征，可结合置换重要性或 SHAP，并谨慎解释相关特征。

## 7. 集成学习

### Bagging 与随机森林

对不同自助采样数据训练多棵树并平均，主要降低方差。随机森林还在每次切分只考虑随机特征子集，进一步降低树之间相关性。

### Boosting

顺序加入弱学习器，后续模型重点修正当前残差。梯度提升可看成在函数空间做梯度下降：

\[
F_m(x)=F_{m-1}(x)+\eta h_m(x)
\]

XGBoost、LightGBM、CatBoost 是表格任务常见强基线。学习率与树数量相互作用：较小学习率通常需要更多树。

### Stacking

使用一级模型的折外预测训练二级模型。必须用折外预测，直接用训练拟合值会泄漏并严重过拟合。

## 8. 不平衡分类

准确率可能完全误导。处理方式：

- 使用 ROC-AUC、PR-AUC、F1、召回率或成本函数。
- 调整分类阈值，而不只是默认 0.5。
- 类别权重或代价敏感学习。
- 只在训练折内做过采样/欠采样。
- 评估概率校准与不同群体表现。

不要在拆分之前做 SMOTE，否则合成样本可能把邻域信息泄漏到验证集。

## 9. 模型选型速览

| 情形 | 优先尝试 | 原因 |
|---|---|---|
| 需要可解释基线 | 线性/逻辑回归 | 快、稳定、系数可检查 |
| 中小型表格数据 | 梯度提升树 | 强非线性、少预处理 |
| 高维稀疏文本 | 线性模型/朴素 Bayes | 可扩展、基线强 |
| 中小样本复杂边界 | RBF-SVM | 核方法表达力强 |
| 局部相似性可靠 | KNN | 假设简单、无需训练 |
| 图像/语音/文本大数据 | 深度网络 | 自动表示学习 |

没有模型能替代正确的数据拆分和评估设计。
