# 09｜评估、统计与模型调试

## 1. 分类混淆矩阵

| | 真实正类 | 真实负类 |
|---|---:|---:|
| 预测正类 | TP | FP |
| 预测负类 | FN | TN |

\[
\mathrm{Precision}=\frac{TP}{TP+FP},\quad
\mathrm{Recall}=\frac{TP}{TP+FN}
\]

\[
\mathrm{Specificity}=\frac{TN}{TN+FP},\quad
F1=\frac{2PR}{P+R}
\]

- Precision：报出的正例中多少是真的。
- Recall：真实正例中找到了多少。
- Specificity：真实负例中排除了多少。
- F1：precision 与 recall 的调和平均，但忽略 TN。

## 2. ROC-AUC 与 PR-AUC

ROC 曲线画不同阈值下 TPR 对 FPR；ROC-AUC 可解释为随机正例得分高于随机负例的概率。PR 曲线画 precision 对 recall，在正例极少时通常更能反映实际检索质量。

AUC 衡量排序，不保证概率校准，也不对应某个运营阈值。部署仍需选阈值并报告该点的成本、召回、精确率和容量。

## 3. 多分类平均方式

- Macro：每类指标等权，关注小类。
- Micro：汇总所有样本，更受大类影响。
- Weighted：按各类样本数加权。

必须明确报告方式。类别不平衡时只写“F1”是不完整的。

## 4. 回归指标

| 指标 | 特点 | 注意事项 |
|---|---|---|
| MAE | 线性惩罚，直观稳健 | 对大误差不特别敏感 |
| MSE/RMSE | 强惩罚大误差，可微 | 对离群点敏感 |
| \(R^2\) | 相对均值基线的改进 | 可为负，不代表因果解释度 |
| MAPE | 相对误差易解释 | 真实值近 0 时失效 |

最好同时报告一种绝对尺度指标和误差分布，例如分位数、最坏组表现。

## 5. 概率校准

若模型对一批样本预测 0.8，这批样本约 80% 真为正类，才称校准良好。常用：

- Reliability diagram。
- Brier score。
- Expected Calibration Error（依赖分箱方式）。
- 后处理：Platt scaling、isotonic regression、temperature scaling。

校准集必须独立于模型训练。分布变化后校准也会失效。

## 6. 置信区间

单个分数没有表达采样不确定性。可使用 bootstrap：从测试样本有放回重采样，重复计算指标，用分位数构造区间。对成组或时间相关数据，应按组或时间块重采样，不能假装样本独立。

测试集太小时，置信区间宽是事实，不应通过只报告最好随机种子掩盖。

## 7. 模型比较与统计检验

比较两个模型要使用同一测试样本的配对差异。分类可考虑 McNemar 检验，连续指标可对样本级差异 bootstrap。交叉验证各折并非完全独立，简单 t 检验常不合适。

统计显著不等于实际重要。应同时报告效应大小、区间、成本和多重比较问题。

## 8. 超参数选择偏差

尝试越多配置，验证集上的最好结果越可能包含“运气”。若需要无偏估计，可用嵌套交叉验证：外层评估，内层调参。测试集被反复查看后，事实上已变成验证集。

## 9. 误差分析模板

建立包含以下字段的表：

```text
样本 ID | 真实标签 | 预测 | 概率 | 数据来源 | 人群/场景 | 错误类型 | 备注
```

优先看：

- 高置信错误：可能是标签错、泄漏、伪相关或严重盲点。
- 临界样本：决定阈值附近表现。
- 各群体最差切片：发现平均数掩盖的问题。
- 模型分歧样本：不同归纳偏置暴露的信息。

## 10. 可解释性

- 全局解释：整个模型依赖哪些特征、响应曲线如何。
- 局部解释：为何对某个样本这样预测。
- 内在可解释：模型结构本身较透明。
- 事后解释：用近似方法解释复杂模型。

置换重要性、PDP、ICE、SHAP 等都有假设。相关特征会让重要性在变量之间分摊或产生不现实的特征组合。解释预测机制不等于发现因果机制。

## 11. 鲁棒性与公平性

做扰动、缺失、噪声、域变化和对抗压力测试。公平性指标之间可能互不兼容；需要明确受保护群体、风险承担者和决策语境。模型公平不能修复整个采集与决策流程的不公平。

## 12. 调试顺序

```text
1. 标签和样本是否正确
2. 数据拆分是否泄漏
3. 指标代码是否正确
4. 简单基线是否合理
5. 小数据能否过拟合
6. 训练曲线与梯度是否正常
7. 错误集中在哪些切片
8. 最后才是换更复杂架构
```
