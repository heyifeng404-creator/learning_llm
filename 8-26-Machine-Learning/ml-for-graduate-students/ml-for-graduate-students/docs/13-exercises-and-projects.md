# 13｜练习、实验与研究项目

## 使用方式

练习分四级：

- L1 概念：不用代码，要求说清机制。
- L2 推导：独立完成关键公式。
- L3 实验：写代码验证假设，而非只跑模型。
- L4 研究：提出问题、设计证据、报告边界。

每次提交建议包含 `README + code + config + raw results + report`。报告必须写失败尝试和误差分析。

## 实验 1：偏差、方差与正则化

### 任务

生成带噪声的一维非线性数据，用 1、3、5、10、20 阶多项式回归拟合；对每个阶数重复采样 30 次。

### 要回答

1. 训练误差和测试误差随阶数怎样变化？
2. 固定测试点的预测方差怎样变化？
3. Ridge 如何改变结果？
4. 增加样本数主要改善哪一部分？

### 验收

至少给出学习曲线、误差分解近似图和一段对“复杂度”的解释。不能只报告最佳阶数。

## 实验 2：数据泄漏挑战

### 任务

故意实现以下两个错误版本，再与正确 Pipeline 比较：

- 全数据标准化后交叉验证。
- 全数据选择与标签相关性最高的特征后交叉验证。

在高维、小样本、随机标签数据上观察分数。

### 要回答

为什么随机标签也可能得到看似不错的验证分？泄漏发生在哪一步？嵌套交叉验证能解决什么、不能解决什么？

## 实验 3：不平衡分类与阈值

### 任务

构造正例比例为 1% 的数据，比较逻辑回归、随机森林和梯度提升。报告 accuracy、ROC-AUC、PR-AUC、precision@k、recall 和成本。

设置：漏掉一个正例成本 20，误报成本 1。用验证集选择阈值，在测试集计算总成本。

### 验收

说明为什么默认 0.5 阈值不是答案，以及重采样应放在交叉验证管线的什么位置。

## 实验 4：从零反向传播

### 任务

扩展 `neural_network_from_scratch.py`：

1. 支持任意层数。
2. 增加 tanh 与 Leaky ReLU。
3. 实现 mini-batch SGD、Momentum 和 Adam。
4. 对每组参数做随机抽样梯度检查。

### 加分项

记录各层激活均值/方差和梯度范数，解释不同初始化下的梯度消失或爆炸。

## 实验 5：表示与聚类的脆弱性

### 任务

在原始特征、标准化特征、PCA 特征和随机投影上分别运行 K-Means、GMM 与 DBSCAN。

### 要回答

- 不同表示如何改变“距离”的含义？
- 内部聚类指标与外部标签指标是否一致？
- 换随机种子或删除 5% 样本后，簇是否稳定？
- 你能否找到轮廓系数高但业务无意义的结果？

## 实验 6：模型校准

### 任务

比较逻辑回归、随机森林、SVM 和神经网络的可靠性图、Brier score 与 ECE。使用独立校准集做 Platt scaling、isotonic regression 或 temperature scaling。

### 要回答

排序能力、分类准确率和概率校准是否可能彼此矛盾？样本少时 isotonic 为什么容易过拟合？

## 实验 7：小型论文复现

### 步骤

1. 选择一篇数据公开、算力可承受、核心实验清楚的论文。
2. 写一页复现契约：核心主张、目标数字、允许差异、预算和停止规则。
3. 先复现最简单基线，再复现核心方法。
4. 对数据、预处理、超参数和评估逐项核对。
5. 报告结果差异以及最可能的三个原因。

### 评分维度

结果接近程度只占一部分；更重要的是透明记录、诊断证据和他人可重复性。

## 综合项目 A：表格风险预测

### 场景

预测未来 30 天内的高风险事件。数据包含数值、类别、时间、重复用户和极不平衡标签。

### 必须完成

- 按用户分组且按时间切分。
- 建立规则、逻辑回归和梯度提升基线。
- 防泄漏特征管线与交叉验证。
- 成本敏感阈值选择、概率校准、bootstrap 区间。
- 按时间、群体、来源做误差切片。
- 写一张部署前监控表和模型卡。

## 综合项目 B：文本分类与域外评估

### 场景

训练数据来自一个平台，测试数据来自不同时间和另一个平台。

### 必须完成

- 多数类、TF-IDF + 线性模型、预训练模型三个层次基线。
- 同域与跨域两套测试。
- 词汇、长度、主题和标签比例漂移分析。
- 对高置信错误做人工编码。
- 比较全量微调与参数高效微调的性能和成本。

## 综合项目 C：视觉小样本迁移

### 场景

每类只有少量标注图像，且数据来源存在设备差异。

### 必须完成

- 冻结特征、部分解冻、全量微调对比。
- 增强策略消融，验证每种增强是否保持标签语义。
- 按设备来源报告性能。
- 画混淆矩阵与典型错误。
- 记录 GPU 时间、显存和推理延迟。

## 开放研究题方向

以下不是现成题目，而是生成研究问题的起点：

- 分布变化下，哪些表示保持稳定，为什么？
- 置信度与真实知识边界为什么不一致？
- 数据质量、数据规模和模型规模的边际收益如何比较？
- 消融结论能否跨架构或跨数据集成立？
- 检索增强何时改善事实性，何时引入错误证据？
- 参数高效微调的能力边界与遗忘机制是什么？
- 相同平均性能下，模型对最坏群体的风险为何不同？

把方向变成问题时，必须明确可测机制与反证条件。

## 自我评分量规（100 分）

| 维度 | 分数 | 判断标准 |
|---|---:|---|
| 问题定义 | 15 | 明确、可证伪、与指标一致 |
| 数据与拆分 | 15 | 无泄漏，偏差与边界透明 |
| 基线与实现 | 15 | 简单/强基线齐全，比较公平 |
| 统计与评估 | 15 | 多种子、区间、切片和成本 |
| 机制与消融 | 15 | 证据直接支持核心主张 |
| 误差与失败 | 10 | 有系统分类和诊断证据 |
| 复现性 | 10 | 环境、配置、数据、结果可追踪 |
| 表达 | 5 | 图表清楚，结论不过度外推 |

一个高分项目不一定模型最复杂，但一定问题清楚、证据可靠、边界诚实。
