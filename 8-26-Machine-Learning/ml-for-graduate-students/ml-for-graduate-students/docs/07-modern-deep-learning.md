# 07｜现代深度学习架构

## 1. CNN：局部性与权重共享

卷积核在空间滑动，同一组权重检测不同位置的局部模式。其归纳偏置是：局部邻域重要，模式平移后仍有相似意义。

输出尺寸（单维）为：

\[
\left\lfloor\frac{W+2P-K}{S}\right\rfloor+1
\]

其中输入宽度 \(W\)、padding \(P\)、核大小 \(K\)、步幅 \(S\)。多层卷积逐渐扩大感受野，从边缘到纹理再到高层语义。残差连接：

\[
y=F(x)+x
\]

提供短梯度路径，让很深的网络更容易优化。

## 2. RNN、LSTM 与序列

RNN 递归更新状态：

\[
h_t=\phi(W_xx_t+W_hh_{t-1}+b)
\]

反向传播需跨时间链式相乘，容易梯度消失或爆炸。LSTM/GRU 用门控控制信息保留与遗忘，改善长期依赖，但序列计算难以完全并行。

## 3. 注意力

缩放点积注意力：

\[
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

直觉：每个 query 根据与各 key 的相似度，对 value 加权汇总。除以 \(\sqrt{d_k}\) 防止内积随维度增大导致 softmax 过度尖锐。

多头注意力让模型在不同子空间学习不同关系。自注意力中 Q、K、V 来自同一序列；交叉注意力中 query 与 key/value 来自不同来源。

## 4. Transformer

典型块包含：

```text
输入表示 + 位置编码
  → 多头注意力 → 残差 + LayerNorm
  → 前馈网络   → 残差 + LayerNorm
```

- Encoder-only：双向上下文，适合理解和表征，如 BERT 类模型。
- Decoder-only：因果遮罩，只看过去，适合自回归生成，如 GPT 类模型。
- Encoder–decoder：输入编码与条件生成，如翻译和摘要。

自注意力对序列长度通常有 \(O(n^2)\) 时间/内存成本，长上下文研究围绕稀疏注意力、线性注意力、状态空间模型和高效内核展开。

## 5. 预训练与迁移学习

预训练在大规模数据上学习通用表示，再适配目标任务：

- 特征提取：冻结骨干，只训练任务头。
- 全量微调：更新全部参数，能力强但成本高。
- 参数高效微调：Adapter、LoRA、Prompt tuning。
- 领域继续预训练：先适应领域语料，再做任务微调。

迁移是否有效取决于预训练数据、任务相似度、规模与适配策略；领域差异大时也会负迁移。

## 6. 自监督学习

从数据本身构造监督信号：

- 掩码建模：预测被遮住的 token/patch。
- 自回归建模：预测下一个元素。
- 对比学习：拉近正样本表示，推远负样本。
- 教师—学生：用一个网络产生目标训练另一个网络。

核心不是“没有监督”，而是不依赖人工语义标签。

## 7. 图神经网络

消息传递框架：

\[
m_v^{(l)}=\mathrm{AGG}\{\phi(h_v^{(l)},h_u^{(l)},e_{uv}) : u\in\mathcal N(v)\}
\]
\[
h_v^{(l+1)}=\psi(h_v^{(l)},m_v^{(l)})
\]

聚合函数应对邻居排列不敏感。常见问题包括过平滑、长距离依赖困难、异配图表现下降和大图采样成本。

## 8. 生成模型

### 自回归模型

用链式法则分解联合分布：

\[
p(x)=\prod_t p(x_t\mid x_{<t})
\]

似然训练清晰，生成必须逐步进行。

### VAE

引入潜变量 \(z\)，最大化证据下界：

\[
\mathrm{ELBO}=\mathbb E_{q(z\mid x)}[\log p(x\mid z)]-D_{KL}(q(z\mid x)\Vert p(z))
\]

第一项保证重构，第二项让潜空间接近先验并可采样。

### GAN

生成器与判别器对抗训练，可产生锐利样本，但可能不稳定、模式崩塌，且缺少易比较的显式似然。

### 扩散模型

前向过程逐渐加噪，模型学习反向去噪。训练稳定、样本质量高，但传统采样需要多步迭代。可从去噪、score matching 或随机微分方程视角理解。

## 9. 大模型的核心议题

- Scaling law：性能随数据、参数、计算按经验规律变化。
- In-context learning：参数不更新时利用提示中的示例完成任务。
- 检索增强：把外部知识检索结果加入上下文，改善时效与可追溯性。
- 对齐：监督微调、偏好优化和安全约束，使行为符合人类意图。
- 幻觉：流畅生成不等于事实正确，需检索、工具、验证与不确定性表达。
- 评估污染：训练数据可能包含基准题，导致分数高估真实泛化。

## 10. 选择架构的原则

从数据结构和约束出发：空间局部性选 CNN，关系结构选 GNN，长程序列依赖选 Transformer，数据小则优先迁移学习。不要因为架构流行就忽略简单基线、数据质量与计算预算。
