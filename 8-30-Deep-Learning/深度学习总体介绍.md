# 深度学习总体介绍：从神经网络到大语言模型

## 1. 深度学习在学习什么

深度学习用参数化函数近似数据中的复杂映射。给定输入 \(x\)、目标 \(y\) 和参数 \(\theta\)，模型产生预测 \(\hat y=f_\theta(x)\)，损失函数 \(L(\hat y,y)\) 衡量预测误差，优化器通过梯度下降更新参数：

\[
\theta_{t+1}=\theta_t-\eta\nabla_\theta L
\]

这里的核心不是“网络越深越好”，而是三个相互制约的因素：模型提供表示能力，数据提供学习信号，优化过程决定能否找到泛化良好的参数。

## 2. 一次训练迭代的完整链路

1. **数据采样**：从训练集取一个 mini-batch。
2. **前向传播**：模型把输入逐层变换成预测。
3. **损失计算**：分类常用交叉熵，回归常用均方误差，语言模型常用 token 级交叉熵。
4. **反向传播**：链式法则把损失对输出的梯度传回所有可训练参数。
5. **参数更新**：SGD、AdamW 等优化器根据梯度更新权重。
6. **评估与诊断**：在未参与更新的数据上观察损失、准确率、困惑度及任务指标。

训练代码中通常对应以下固定模式：

```python
optimizer.zero_grad()
prediction = model(batch_x)
loss = criterion(prediction, batch_y)
loss.backward()
optimizer.step()
```

## 3. 必须掌握的数学支点

### 3.1 张量与线性代数

张量是带形状的多维数组。LLM 中最常见的三维张量形状是 `[batch, sequence, hidden]`。矩阵乘法用于特征投影，逐元素运算用于激活与门控，广播用于共享偏置或 mask。

### 3.2 链式法则与自动微分

若 \(z=f(y)\)、\(y=g(x)\)，则 \(\frac{dz}{dx}=\frac{dz}{dy}\frac{dy}{dx}\)。深度网络只是把这条规则应用到一个大型有向无环计算图。PyTorch Autograd 保存必要的中间量，并在 `backward()` 时反向累积梯度。

### 3.3 概率与交叉熵

语言模型输出词表上每个 token 的 logits。Softmax 将 logits 变成概率，交叉熵最大化正确 token 的对数似然：

\[
L=-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i\mid x_i)
\]

### 3.4 优化与泛化

- 学习率过大可能震荡或发散，过小则收敛慢。
- Momentum 利用历史方向，Adam 自适应缩放不同参数的更新。
- AdamW 将权重衰减与梯度更新解耦，是 Transformer 训练的常见选择。
- Dropout、权重衰减、早停和数据增强用于减轻过拟合。

## 4. 从 token 到上下文表示

文本首先被分词器映射成整数 token。Embedding 表把每个 token id 映射为连续向量。仅有 token embedding 不包含顺序，因此 Transformer 通常还加入位置编码。

对输入矩阵 \(X\)，自注意力先构造查询、键、值：

\[
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
\]

然后计算：

\[
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V
\]

其中 \(M\) 是 mask。GPT 使用因果 mask，保证位置 \(t\) 不能看到未来 token。除以 \(\sqrt{d_k}\) 是为了避免点积随维度增大而导致 Softmax 过度饱和。

## 5. Transformer Block 的结构

一个典型的预归一化 Decoder Block 包含：

```text
x ── LayerNorm ── Causal Self-Attention ── + ── LayerNorm ── MLP ── +
│                                           ↑                      ↑
└───────────────────────────────────────────┘                      │
└──────────────────────────────────────────────────────────────────┘
```

- **多头注意力**让不同子空间分别学习位置、句法、指代或主题关系。
- **前馈网络**对每个位置独立进行非线性变换，常把隐藏维度扩展约 4 倍。
- **残差连接**提供短梯度路径。
- **LayerNorm**稳定不同样本和位置上的激活尺度。

## 6. GPT 的训练目标与生成过程

GPT 是自回归语言模型，将序列概率分解为：

\[
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})
\]

训练时输入和标签错开一个位置，例如输入“深度学习”，目标是“度学习…”。由于整段目标已知，训练可并行计算所有位置的损失；生成时未来 token 未知，必须逐 token 迭代。

生成策略决定“从概率分布选哪个 token”：

- Greedy：每次取最大概率，稳定但可能重复。
- Temperature：小于 1 更保守，大于 1 更多样。
- Top-k：只从概率最高的 k 个候选中采样。
- Top-p：从累计概率达到 p 的最小候选集合中采样。

## 7. 预训练、监督微调与 LoRA

- **预训练**：在大规模文本上学习下一个 token，获得通用语言与知识表示。
- **监督微调（SFT）**：用指令—回答数据让模型遵循任务格式。
- **偏好对齐**：使用人类或模型偏好信号改善有用性与安全性。
- **LoRA**：冻结原权重 \(W\)，只学习低秩增量 \(\Delta W=BA\)，其中秩 \(r\) 远小于输入/输出维度。它显著减少可训练参数和优化器状态。

LoRA 并不减少基础模型前向传播所需的全部计算和显存；它主要降低可训练参数、梯度和优化器状态的成本。

## 8. 评估不能只看训练损失

语言模型常用困惑度 \(\mathrm{PPL}=\exp(L)\)，它反映模型对测试 token 的平均不确定性，但不能完整代表事实性、安全性或任务完成质量。

合理评估应同时包含：

- 留出集 loss / perplexity；
- 下游任务的准确率、F1、ROUGE 等任务指标；
- 生成质量、事实性、鲁棒性和安全性测试；
- 不同种子、不同数据切片上的方差；
- 推理延迟、吞吐、显存和成本。

必须防止训练/测试污染。若测试答案出现在训练语料中，优秀分数可能只是记忆而非泛化。

## 9. 训练中的常见故障

| 现象 | 常见原因 | 优先检查 |
|---|---|---|
| loss 不下降 | 标签错位、学习率不合适、参数未注册 | 单 batch 过拟合、梯度是否非零 |
| loss 变 NaN | 学习率过大、数值溢出、非法除法 | 梯度范数、输入范围、混合精度 |
| 训练好验证差 | 过拟合或分布偏移 | 数据划分、正则化、重复样本 |
| 生成重复 | 数据单一或采样过于确定 | temperature、top-k/top-p、训练语料 |
| 注意力泄露未来 | 因果 mask 方向或形状错误 | 打印注意力矩阵上三角区域 |
| OOM | batch/序列/模型过大 | 梯度累积、混合精度、检查点技术 |

## 10. 实验方法与可复现性

研究生层面的实验应写清：研究问题、对照组、变量、指标、随机种子、软硬件环境和失败案例。一次只改变一个关键因素；至少重复多个随机种子，并报告均值与方差。保存配置和版本比只保存最终权重更重要。

建议每章完成如下记录：

1. 关键张量的形状和含义。
2. 训练前后的损失、指标与一段样例输出。
3. 一个消融实验，例如去掉缩放、mask、残差或权重衰减。
4. 对结果的解释以及仍不能证明的结论。

## 12. 进一步深入的方向

- 分词：BPE、WordPiece、Unigram，以及多语言词表设计。
- 架构：RoPE、RMSNorm、SwiGLU、Grouped-Query Attention、Mixture of Experts。
- 长上下文：位置外推、稀疏注意力、KV Cache 与检索增强。
- 训练系统：数据并行、张量并行、流水线并行、ZeRO/FSDP。
- 对齐与评估：SFT、DPO、奖励模型、红队测试和可解释性。
- 推理优化：量化、蒸馏、投机解码、连续批处理。

完成本项目后，建议选一个公开小语料，把字符级分词替换为子词分词，扩大模型并建立严格验证集，再尝试一个参数高效微调任务。
